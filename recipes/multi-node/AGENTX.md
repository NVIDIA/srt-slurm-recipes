# Multi-Node AgentX Recipes

Ported SemiAnalysis InferenceX **agentic-coding** (`cc-traces-weka`) serving
configs. GLM / GLM-5.x are excluded. **Not pushed.**

Single-node AgentX (B200 / B300 / H100 / H200) lives in
[recipes/single-node/AGENTX.md](../single-node/AGENTX.md).

GB200 / GB300 NVL72 points that the dashboard labels **Single-node aggregate**
still belong in this tree. That label means one aggregated worker on a slice of
the rack (for example Qwen3.5 FP4 GB300 SGLang TP2, two chips, conc 48), not a
B200/B300 bash campaign. InferenceX published those as YAML under
`benchmarks/multi_node/srt-slurm-recipes/`, so they are copied here next to the
disagg recipes rather than generated under `recipes/single-node/`.

## Requires an InferenceX checkout

Every recipe below runs its benchmark from
[`agentic_srt.sh`](https://github.com/SemiAnalysisAI/InferenceX/blob/main/benchmarks/multi_node/agentic_srt.sh),
which lives in InferenceX rather than in `srt-slurm` or this repository. `srtctl`
mounts `INFMAX_WORKSPACE` at `/infmax-workspace` to supply it:

```bash
git clone --recurse-submodules https://github.com/SemiAnalysisAI/InferenceX.git
export INFMAX_WORKSPACE=/shared/path/to/InferenceX
```

Submodules matter: `benchmark_lib.sh` installs `-e utils/aiperf`, which is a
submodule. The path must be visible from the compute nodes, since it is
bind-mounted straight into the container. Run `srtctl dry-run -f <recipe>` first
to confirm the mount appears. See
[Requires an InferenceX checkout](../../README.md#requires-an-inferencex-checkout).
