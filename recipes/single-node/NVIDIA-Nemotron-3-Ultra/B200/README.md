# NVIDIA-Nemotron-3-Ultra B200 recipes

Baseline recipes are adapted from an NVIDIA-internal IBDB gold study of
`nemotron-ultra-v3-rl3-mixed` at 50000/2048 ISL/OSL. Optimized points come from
NVIDIA-internal `lights-out-inference` runs. Neither source is public, so this
directory carries the resulting configurations rather than links to them.
